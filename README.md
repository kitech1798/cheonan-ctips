# 천안 교통 아틀라스 C-TIPS

천안시 AI·데이터 활용 공모전 출품작. 사고·인구·고령·버스·정류장·교통카드 **6종 공공데이터**를 31개 읍·면·동에 결합해 교통 문제를 **진단 → 유형화 → 처방**하는 인터랙티브 웹 서비스.

**Cheonan Traffic Issue Prescription System** — 데이터로 진단하고, 해법으로 연결하는 천안 교통 개선 플랫폼.

## 구성 (자체완결 단일 페이지)
- **🗺️ 지도** — 4대 유형 색지도(위험도·대중교통·고령 등 9개 지표 전환) + 사고 다발 142곳 + 동 클릭 진단서
- **📊 통계** — KPI · 대중교통 이용 프로파일(시간대·이용자·지역·정책후보) · 문제별 랭킹 · 31개 전체 진단표
- **💡 개선안** — 5가지 발견 · 우선 개선 대상 · 유형별 처방 · 정책 사업화 보드

`index.html` 하나에 데이터를 내장(window.__DATA) — 지도 타일만 인터넷 사용.
